# Knowledge base

The coach's science, in short rules. It is part of the system prompt, sent with every call and
read from cache, so it stays compact. Each rule carries its register:

- **[formula]**: a defined calculation. The program computes it; the coach quotes the result.
- **[evidence]**: supported by the studies listed in REFERENCES.md.
- **[convention]**: a coaching rule of thumb. Useful, not measured, not universal. Never present one
  as a research finding.

| File | Use it for |
|---|---|
| readiness.md | the morning call: recovery signals, health markers, feel against numbers |
| load.md | load, fitness, fatigue, form, how fast load may rise |
| zones.md | zones and field tests in the three sports |
| bike.md, run.md, swim.md | session reviews, sport by sport |
| strength.md | Crossfit and strength sessions |
| periodization.md | plans, phases, taper, feasibility |
| sessions.md | how to judge one session against its plan |
